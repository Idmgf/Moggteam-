# QR-код для печати

Код на упаковке ведёт на `https://YOUR-DOMAIN.kz/`. Не заменяйте этот плейсхолдер вымышленным доменом: после выбора домена создайте векторный SVG командой:

```bash
npm run qr -- https://YOUR-DOMAIN.kz/
```

Требования к печати:

- размер не менее 20 × 20 мм;
- тихая зона — не менее 4 модулей (скрипт создаёт `margin: 4`);
- высокий контраст: тёмный код на светлой подложке, без узора под ним;
- коррекция ошибок не ниже уровня M (в скрипте — M);
- передавать в типографию SVG или PDF, не растровый скриншот;
- до печати проверить сканирование с нескольких телефонов, в том числе при слабом освещении и на финальном материале упаковки.

Корень `/` и маршрут `/code` являются постоянными публичными адресами. Внутренние маршруты промо-механики не должны попадать в QR на тираже.
