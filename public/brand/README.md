# Фирменный знак

`provided-brand-mark.png` — файл, предоставленный в рабочей папке для текущего прототипа. Не изменяйте его пропорции, цвета и не обрезайте охранное поле.

Перед публикацией положите согласованные оригиналы из Stavleak в эту папку:

- `logo-primary.png` — основной;
- `logo-monochrome.png` — монохромный;
- `logo-white-on-blue.png` — белый вариант на синем фоне.

Для каждого варианта используйте контрастный фон и свободное поле вокруг знака. Не воспроизводите логотип средствами CSS/SVG и не перекрашивайте его.
