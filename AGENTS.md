# TAMYR POP — правила проекта

- Стек: Next.js App Router, TypeScript, Tailwind CSS, PostgreSQL + Prisma, Zod.
- Команды: `npm run setup`, `npm run dev`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
- UI mobile-first; интерфейс KZ/RU, казахский указан первым. Тексты живут в `src/i18n`, не в компонентах.
- Пользовательские данные, коды и баллы хранятся только в PostgreSQL; секреты — только в env.
- Не выдумывать домен, ключи, поставщика SMS, юридические формулировки, сроки акции, правила розыгрыша, стоимость призов, логотип или свойства продукта вне ТЗ.
- Не логировать телефоны или секреты; операции с кодами проводить транзакционно.
